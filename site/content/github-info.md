# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Official sources to watch

- **GitHub Blog** (`github.blog/latest/`): good for feature announcements, product direction, and practical examples you can adapt into your own workflow.
- **GitHub Changelog** (`github.blog/changelog/`): useful for release notes and behavior changes that may affect how teams use GitHub day to day.
- **Awesome Copilot Workflows** (`awesome-copilot.github.com/workflows/`): a reference for workflow patterns you can borrow when building automations that read context and open pull requests.
